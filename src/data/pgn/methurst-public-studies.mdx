## Queen vs Rook — the whole method

Twenty-eight studies, one per idea, working through the queen-versus-rook
endgame from the defender's fortresses to the attacker's ways through them. This
is one exported file: each study below is a folder of chapters, and each chapter
is a position with the author's notes on it.

### Where to start

| Start here | Because |
| --- | --- |
| **Rosettes**, then Adjacent / Opposite / Alternating | the ring the four pieces make is the shape everything else is measured against |
| **Philidor position**, **Euwe position** | the two positions the whole endgame is usually taught from |
| **Body Guard**, **Body Check**, **Thorn** | the attacker's three standard ways of making progress |
| **2nd Rank Fortress**, **Third Rank Defense**, **Corner Defenses** | what the defender is trying to reach |

### How to read a chapter

Every chapter is a set-up position rather than a played game, so open one and
step through it with the arrows — the comments on each move are the study. From
any move you can hand the position to the engine or to the Analysis Board with
the buttons above the board.

Written by [methurst](https://lichess.org/@/methurst) and published as public
lichess studies in July 2021.
